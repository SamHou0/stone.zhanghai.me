# 《红楼梦》白话文翻译工作说明

## 目标

把《红楼梦》每一回的正文逐段翻译成准确、通顺的现代简体中文白话文。原文和脂批都不能改动，译文单独写入 JSON 文件，随后由构建脚本插入网页。

## 输入

- `_blocks/NN.txt`：已按 `### 001` 编号列出第 NN 回的正文段落，脂批已剔除。每个编号对应网页中原文段落下方要插入的一段译文。
- `NN.htm`：该回原网页，可在需要时阅读上下文，但**绝对不要修改**。
- 不要翻译 `_blocks` 中不存在的段落，不要合并或拆分编号。

## 输出

写入 `translations/NN.json`，格式为：

```json
{
  "001": "第一段的白话文译文。",
  "002": "第二段的白话文译文。",
  "...": "..."
}
```

- 键必须是三位字符串编号，且与 `_blocks/NN.txt` 完全一致，不能多、不能少。
- 值必须是该段完整译文，不能为空，不能只写“略”“见原文”等。
- JSON 必须合法，UTF-8，不要加 Markdown 代码围栏。
- 只允许写 `translations/NN.json`，不要修改其他文件。

## 翻译标准

1. **准确**：忠实传达原文的人物、动作、对话、因果、典故、语气和潜台词，不漏掉信息，不凭空增补情节，不把原文改写成梗概。
2. **白话**：用现代人读得懂的简体中文，句子通顺自然。可以保留《红楼梦》的人名、地名、称谓、诗词名和必要的古代名物，但要用白话把意思说清楚。
3. **对话**：保留对话的层次和人物口吻；该尖刻的尖刻，该委婉的委婉，不要把所有人都翻译成同一种腔调。
4. **诗词、偈语、对联、曲词**：要译出意思和情感，可以译成现代白话诗句或散文式白话，但不要只写“这首诗表达了……”之类的赏析。尽量避免照抄原文文言。
5. **注释**：输入已经剔除脂批，译文中也不要加入脂批或研究性评论。
6. **专名**：人名、地名、官职、器物名保持原著用法；如原文有明显通假、异体或错字，按上下文理解后翻译，不要擅自改原文。
7. **段落对应**：一段原文对应一段译文；原文中的多句对话仍放在同一段译文中。诗体段落可以保留分行（JSON 字符串中用 `\n`）。
8. **长度**：译文应完整，一般不少于原文长度的 45%；不要为了简短而删减情节。

## 自检

完成后运行：

```bash
python3 _validate_translations.py NN
```

必须看到 `NN: OK` 且 `chapters_with_problems: 0`。如果提示 missing / extra / suspicious_short，请补齐或改写后再次运行。

## 注意

- 不要修改 `NN.htm`、`_blocks/*`、其他回的 JSON 或任何脚本。
- 如果原文段落很长，宁可多写几句，也不要截断。
- 翻译时以“让现代读者不用查字典就能读懂这一段”为标准。
